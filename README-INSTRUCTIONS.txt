RedLine Studio BD Professional Website - GitHub Pages Upload Guide

WHAT IS INSIDE
- index.html: main professional website
- styles.css: website design and responsive layout
- support.html: support/contact page
- privacy.html: privacy policy page
- app-ads.txt: placeholder file for AdMob app-ads.txt
- assets/: images used by the website, including Road Fight and ICE Crusher
- .nojekyll: helps GitHub Pages serve files normally

BEFORE UPLOADING
1. Open index.html, support.html, and privacy.html.
2. Replace YOUR_SUPPORT_EMAIL@gmail.com with your real Play Console support email.
3. In index.html, replace YOUR_ICE_CRUSHER_PLAY_STORE_LINK with your real ICE Crusher Google Play link.
4. After AdMob gives you your real publisher ID, update app-ads.txt.

HOW TO UPLOAD TO GITHUB PAGES
1. Open your GitHub repository: redlinestudiobd.github.io
2. Upload the files and the assets folder from this package directly into the repository root.
3. Make sure index.html is in the root, not inside another folder.
4. Commit the changes.
5. Visit: https://redlinestudiobd.github.io/

IMPORTANT
Do not upload the zip file itself to GitHub Pages. Extract it first, then upload the actual files.
